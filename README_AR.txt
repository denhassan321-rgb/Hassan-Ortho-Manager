مشروع Android Studio — إدارة عيادة التقويم

المتطلبات:
- كمبيوتر Windows.
- Android Studio حديث.
- اتصال إنترنت أول مرة لتنزيل مكونات Gradle وAndroid SDK.

خطوات إنشاء APK:
1) فك ضغط الملف ZIP إلى مجلد على الكمبيوتر.
2) افتح Android Studio واختر Open.
3) اختر مجلد OrthodonticClinicAndroid (المجلد الذي يحتوي settings.gradle).
4) انتظر Gradle Sync. إذا طلب تنزيل SDK 35 أو JDK 17 وافق.
5) من القائمة Build اختر Build Bundle(s) / APK(s) ثم Build APK(s).
6) بعد انتهاء البناء اضغط Locate من إشعار Android Studio. ستجد الملف غالبًا داخل:
   app/build/outputs/apk/debug/app-debug.apk
7) انقل app-debug.apk إلى هاتف Android وثبّته. قد يطلب الهاتف السماح بالتثبيت من هذا المصدر.

ميزات النسخة:
- واجهة عربية داخل WebView، وبيانات المرضى محفوظة محليًا على الجهاز.
- إضافة المرضى والخطة العلاجية والتكلفة والدفعات والمواعيد.
- تنبيه قبل الموعد بساعة عند إدخال وقت للموعد، بعد السماح بإشعارات التطبيق.
- تذكير المواعيد يعاد جدولته بعد إعادة تشغيل الهاتف.
- تصدير/استعادة نسخة احتياطية من شاشة النسخ الاحتياطي داخل التطبيق.

مهم:
- أول مزامنة وبناء تحتاج اتصال إنترنت لتنزيل أدوات Android.
- لا تحذف بيانات التطبيق أو تمسح بياناته قبل تصدير نسخة احتياطية.
- هذه نسخة أولية للاستخدام التجريبي؛ اختبرها ببيانات وهمية أولًا قبل إدخال بيانات المرضى الحقيقية.
- النسخة الاحتياطية JSON تحتوي بيانات المرضى، فاحفظها بمكان آمن.
